# 英語點讀百科

兒童英語點讀網站。首頁是虛擬書架，收錄第一冊、第二冊，以及第三冊已完成的單元。可點圖聽發音、看例句，以及玩聽音找圖。

朗讀使用瀏覽器內建語音，沒有另外附上音檔。用 HTTPS 開啟時比較穩定，第一次播放通常要先在頁面上點一下。

## 線上瀏覽

https://etbase.github.io/english-tap-encyclopedia/

本機預覽可以在專案根目錄執行：

```bash
python3 -m http.server 8080
```

然後打開 http://127.0.0.1:8080/

## 目錄

- `index.html`：書架首頁
- `volume1/`：第一冊，第 1–10 單元（探索生活與自然）
- `volume2/`：第二冊，第 11–20 單元（探索世界與旅行）
- `volume3/`：第三冊，目前有第 21–22 單元（史前與遠古）

這是純靜態網站。頁面都使用相對路徑，放在 GitHub Pages 的專案子路徑也能開啟。
